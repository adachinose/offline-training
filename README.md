iPhoneのホーム画面に追加して使うPWAです。Mac、Xcode、App Store公開、Apple Developer Programへの加入は不要です。初回だけHTTPSのWebサイトとして開く必要がありますが、インストール後は通信なしで起動できます。

## 実装済み機能

### タイマー
- 開始前に3秒カウントダウン
- 複数の秒数を順番にカウントダウン
- 1回のみ／指定回数の繰り返し
- 区間ごとに約3秒の簡易リズム音、終了時に別パターンの完了リズム音
- 残り秒数を全画面級の大きさで表示
- 設定の名前付き保存、読込、削除
- 一時停止、再開、最初から、終了
- 実時刻を基準にしたカウントダウン補正

### ランダム方向指示
- 開始前に3秒カウントダウン
- 左前、左、左後、右前、右、右後の6方向
- 画面いっぱいの太い矢印
- 緑とオレンジを1回ごとに交互表示
- 指定間隔1〜10秒
- ランダム範囲1〜10秒（整数、両端を含む）
- 実行時間を秒単位で指定して自動終了（未入力なら停止するまで継続）
- 実行中に回数と残り時間を表示
- 切替時に180ミリ秒だけ矢印を消し、再表示と同時にビープ音
- 設定の名前付き保存、読込、削除
- 一時停止、再開、最初から、終了

### 共通
- 端末内のlocalStorageへ設定を保存
- Service Workerによるオフライン動作
- 対応端末では画面の自動ロックを抑止
- アプリがバックグラウンドに入った場合は自動的に一時停止
- 外部ライブラリ、外部フォント、通信APIは不使用

## WindowsからiPhoneへ入れる方法（GitHub Pages）

1. このZIPをWindowsで展開します。
2. GitHubのアカウントを作成します。
3. GitHubで新しいリポジトリを作成します。GitHub Freeの場合はPublicを選びます。リポジトリ名の例は `offline-training` です。
4. リポジトリ画面の `Add file` → `Upload files` を開き、展開した `training-app` フォルダー内のファイルをすべてアップロードしてコミットします。
5. リポジトリの `Settings` → `Pages` を開きます。
6. `Build and deployment` のSourceを `Deploy from a branch` にします。
7. Branchを `main`、フォルダーを `/(root)` にしてSaveします。
8. 公開が完了すると、同じPages画面に公開URLが表示されます。
9. iPhoneのSafariで公開URLを開きます。
10. 共有ボタン → `ホーム画面に追加` → `追加` を選びます。
11. ホーム画面の「トレーニング」を一度起動します。その後、機内モードでも起動できることを確認します。

公開されるのはアプリのHTML/CSS/JavaScriptだけです。保存した秒数やプリセットはiPhone内に保存され、GitHubには送信されません。

## iPhoneだけで設置する場合

SafariからGitHubを開き、同様にリポジトリ作成、ファイルアップロード、Pages設定ができます。ただし複数ファイルのアップロード操作はWindowsの方が簡単です。

## 使用時の注意

- 音を鳴らすには、開始前にiPhoneの音量を上げてください。音声は開始ボタンの操作を契機に有効化します。タイマーの区間音は約3秒なので、3秒未満の区間では次の区間音によって途中で切り替わります。
- iOSはWebアプリが画面外・ロック中になるとJavaScriptや音声を停止する場合があります。このアプリは誤った進行を避けるため、画面が非表示になると自動で一時停止します。トレーニング中はアプリを前面表示してください。
- 画面が自動消灯する端末では、iPhoneの `設定` → `画面表示と明るさ` → `自動ロック` をトレーニング中だけ `なし` にしてください。対応環境ではアプリ側から画面消灯を抑止します。
- 設定データはSafariのWebサイトデータを削除すると消えます。
- アプリ更新後に古い画面が残る場合は、一度オンライン状態でアプリを終了し、再起動してください。

## ローカル確認（Windows、任意）

フォルダーを直接ダブルクリックすると基本画面は開きますが、Service Workerは動きません。オフライン機能まで確認する場合は、PowerShellまたはコマンドプロンプトでフォルダーへ移動し、Pythonが入っていれば次を実行します。

```text
python -m http.server 8000
```

その後、Windowsのブラウザーで `http://localhost:8000` を開きます。

## ファイル構成

- `index.html`：画面構造
- `styles.css`：表示、全画面レイアウト
- `app.js`：タイマー、方向指示、設定保存、音声
- `sw.js`：オフラインキャッシュ
- `manifest.webmanifest`：ホーム画面アプリ設定
- `icon-192.png`、`icon-512.png`、`apple-touch-icon.png`：アイコン
